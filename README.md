# 🎵 Fxz Music - Android Music Player

---

## 📋 Descripción / Description

**Fxz Music** es una aplicación nativa de reproducción de música para Android, diseñada para ofrecer una experiencia fluida, moderna y de alto rendimiento. Escanea y reproduce archivos de audio locales con una interfaz elegante construida con Jetpack Compose.

**Fxz Music** is a native Android music player application designed to deliver a smooth, modern, and high-performance experience. It scans and plays local audio files with an elegant interface built with Jetpack Compose.

---

## ✨ Características Principales / Key Features

| Característica | Descripción |
|---|---|
| 🎶 **Reproducción Local** | Escanea y reproduce archivos de audio del dispositivo / Scans and plays audio files from your device |
| 🎨 **Interfaz Moderna** | Interfaz intuitiva y elegante con Jetpack Compose / Intuitive and elegant interface with Jetpack Compose |
| ⚡ **Alto Rendimiento** | Código optimizado en Kotlin para máxima velocidad / Optimized Kotlin code for maximum performance |
| 🔄 **Actualizaciones OTA** | Sistema automático de verificación de versiones / Automatic version checking system via JSON |
| 📱 **Experiencia Fluida** | Arquitectura MVVM con Kotlin Coroutines / MVVM architecture with Kotlin Coroutines |
| 💾 **Gestión de Datos** | Base de datos local con Room / Local database with Room |

## 🏗️ Arquitectura / Architecture

La aplicación sigue el patrón **MVVM** (Model-View-ViewModel) con las siguientes características:

- **Separación de responsabilidades** / **Separation of concerns**
- **Reactive programming** con Kotlin Coroutines
- **Inyección de dependencias** / **Dependency Injection**
- **Gestión eficiente de recursos** / **Efficient resource management**

## 📱 Requisitos / Requirements

- **Android:** API 24 (Android 7.0) o superior / or higher
- **RAM:** Mínimo 2GB / Minimum 2GB
- **Almacenamiento:** 50MB de espacio libre / 50MB free storage

## 🔄 Sistema de Actualizaciones OTA / OTA Update System

Fxz Music incluye un sistema inteligente de verificación de versiones mediante JSON que permite:

- Notificaciones automáticas de nuevas versiones
- Descarga segura de actualizaciones
- Compatible con el flujo de versiones en GitHub Releases
